# -pc-status-dynamic-island
小白借助deepseek完成的第一个项目！First project!它显示 CPU 使用率与频率、内存占用、GPU 使用率 / 显存 / 频率，以及游戏帧率。平时贴在屏幕边缘只留一条 16 像素宽的细条，鼠标移上去展开成完整胶囊，移开 0.8 秒后自动收回；可以拖到任意一条边停靠，也可以停在桌面任意位置。细条状态下是一枚角色头像加一颗状态点。  纯 Win32 + C++20，静态链接成单个 exe：免安装、不依赖 VC++ 运行库、不联网、不打日志、不发遥测，也不需要管理员权限。单一采样线程每秒一次，窗口隐藏时自动暂停。常驻内存约 3 MB；开启 GPU 读取时 NVIDIA 的 nvml 接口会额外占用约 19 MB，可用 --no-gpu 关掉。
